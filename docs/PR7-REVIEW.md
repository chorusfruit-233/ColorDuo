# PR #7 审查与实机测试

范围为 [jahn2007 的 PR #7](https://github.com/chorusfruit-233/ColorDuo/pull/7)，原提交 `e295acb1ccfe351d628d5954585356e9d1e99c1d`。整合作者功能与审查、实机反馈修正的版本为 0.3.5。0.3.3、0.3.4 保留为历史测试草稿，当前正式 Latest 仍为 0.2.6。

## 审查补充

- 热重载原实现先拆卸宿主，再等待后台退出；超时拒绝后没有恢复。现先拒绝忙碌采样，验证交接数据后才退场；停止失败保留旧 UI，回调注销失败会重新注册已释放的回调并恢复宿主。未退出的旧线程继续阻止后续卸载。
- 胶囊中部双卡原先使用整枚胶囊的中心，侵占左侧时钟。现使用固定的右侧单元中心，并按点阵实际宽度为时钟等左侧文字留空间；点阵缩放仍保持中心与偏移独立。
- 分离弧原默认开口会压到电量文字。调整新增布局的默认外移、弧高和开口，默认 36 字号可实际绘出 8、84、100；用户缩小或独立调整开口时，按中心两侧可用宽度与实际字形边界拟合文字，覆盖两套桌面字体。经典环形的参数保持原值。
- 暂停充电灰度范围仍默认“全部图标”，新增“仅电量环”供选择；电话服务只在原生网络类型为空时读取。
- 将原 PR 的热重载、绑定过程及格式化检查纳入 CI；补充忙碌、状态验证失败、后台停止超时、回调清理失败与布局重叠检查。

本地 11 组检查、10 个应用设置列表单元测试及 Debug 构建已通过，其中绘制 1697 项、热重载 23 项、原生绑定 36 项；恢复旧胶囊中部锚点会使新增重叠检查失败。

离线检查执行实际 Java 绘图、配置及部分生命周期方法；Android 服务、LSPosed 真实交接、系统字体、GPU 和 ROM 动画仍以手机反馈为准。构建附带的 `layout-preview.png` 来自实际绘图代码与桌面 Canvas，使用模拟数据，属于布局参考图。

## 安装

测试包为 **0.3.5 / 10025**，使用本项目正式签名，可覆盖 0.2.6，保留配置。下载构建产物 ZIP，安装其中的 APK，然后重启一次 SystemUI 或手机。本轮不向模块仓发布，也不将测试草稿设为正式 Latest。


## 新布局

先记录原布局，测试后可切回；安装本身不会自动替换已有布局。

1. 在绘图页保持“环形”，进入“外观”设置，将“环结构”设为“分离双弧”。先保持“左右弧段联动”开启，观察电量数字与弧端是否分离。
2. 进入移动信号设置，将“信号布局”设为“合并堆叠”，再将“堆叠位置”设为中部。分别试上部、中部、下部，再调“信号图标大小”和“双卡排间距”。当前单卡只应显示一排四个点；预览里的第二排来自模拟双卡，不代表真机应有第二排。
3. 关闭“左右弧段联动”，分别调左右弧高、横向半轴、外移和上下开口；再打开联动应恢复对称。可切回“经典”比较。
4. 切换“胶囊”，左侧放时钟，右侧选择“合并堆叠”，检查时钟与信号没有重叠；分别试短、默认、长胶囊。

## 其余验收

- 在亮色、暗色应用，以及锁屏、通知栏、控制面板中切换，检查尺寸、配色、原生图标和时间交接。
- Wi-Fi 连接/断开时检查中部 Wi-Fi 与网络类型候补；停用/启用 SIM 时注册阶段仍留空，没有“正在搜索”或短暂 SOS。
- 插电、满电和原生游戏助手旁路供电下检查颜色、灰度范围、功率和温度；闪电位置菜单设为“不显示”时，模块与系统闪电都应隐藏；选“系统原生”时只交回系统图标，选布局位置时由模块绘制。
- 关闭总开关应恢复原生显示，再开启恢复新布局；重启后所有设置应保留。

双卡物理顺序及切换数据卡需要两张实际 SIM 验收，目前单卡设备只能核对单卡显示。热重载初次覆盖 0.2.6 无法验证，需后续同签名更新或框架主动重载；被拒绝时旧布局应继续工作，重启 SystemUI 可应用新版。

## 0.3.4：根据实机反馈调整

- “胶囊结构”原来按宽泛的外观归属筛选滑杆，混进了十二个环形专用参数；这些在胶囊中被禁用，还把有效项目推到屏幕之外。现在按结构用途选出五个胶囊参数，并给弹层加上滚动。
- “分别放置”只显示每张卡的位置；“合并堆叠”只显示一个堆叠位置和参与堆叠的卡，外置信号则使用自己的选项。布局模式由已有组件配置推导，没有新增一份模式状态。
- 旧镜像只把下排曲率取反，导致两排向内相撞，单独的 SIM 1 也没有变化。现在同时翻转所有可见行的曲率，保持 SIM 顺序，测量、对齐和绘制使用同一条规则；过粗的点阵保留所需最小排距。
- 新增应用内设置列表单元测试，直接检查项目筛选与可编辑条件；绘制检查覆盖单卡、双卡、交换卡位和加粗点阵。`mirror-preview.png` 提供模拟单卡与双卡的镜像前后参考。

## 0.3.5：统一闪电位置设置

- 只保留“充电闪电的位置”菜单，提供“不显示 / 系统原生”和当前样式的实际位置；胶囊使用上、左、右、下的排列。
- 菜单一次同步可见性和布局，沿用已有配置键；旧版关闭状态优先显示为“不显示”。移除或移动闪电时保留其他组件的优先级顺序。
- 空胶囊不再在未放置闪电时自行绘制一个，保证“系统原生”在空布局下也能生效。已有明确放置的闪电保留原位置。
