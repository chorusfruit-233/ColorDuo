## 审查补充

- 热重载原实现先拆卸宿主，再等待后台退出；超时拒绝后没有恢复。现先拒绝忙碌采样，验证交接数据后才退场；停止失败保留旧 UI，回调注销失败会重新注册已释放的回调并恢复宿主。未退出的旧线程继续阻止后续卸载。
- 胶囊中部双卡原先使用整枚胶囊的中心，侵占左侧时钟。现使用固定的右侧单元中心，并按点阵实际宽度为时钟等左侧文字留空间；点阵缩放仍保持中心与偏移独立。
- 分离弧原默认开口会压到电量文字。调整新增布局的默认外移、弧高和开口，默认 36 字号可实际绘出 8、84、100；用户缩小或独立调整开口时，按中心两侧可用宽度与实际字形边界拟合文字，覆盖两套桌面字体。经典环形的参数保持原值。
- 暂停充电灰度范围仍默认“全部图标”，新增“仅电量环”供选择；电话服务只在原生网络类型为空时读取。
- 将原 PR 的热重载、绑定过程及格式化检查纳入 CI；补充忙碌、状态验证失败、后台停止超时、回调清理失败与布局重叠检查。

本地 11 组检查及 Debug 构建已通过，其中绘制 1420 项、热重载 23 项、原生绑定 36 项；恢复旧胶囊中部锚点会使新增重叠检查失败。

离线检查执行实际 Java 绘图、配置及部分生命周期方法；Android 服务、LSPosed 真实交接、系统字体、GPU 和 ROM 动画仍以手机反馈为准。构建附带的 `layout-preview.png` 来自实际绘图代码与桌面 Canvas，使用模拟数据，属于布局参考图。

## 新布局

先记录原布局，测试后可切回；安装本身不会自动替换已有布局。

1. 在绘图页保持“环形”，进入“外观”设置，将“环结构”设为“分离双弧”。先保持“左右弧段联动”开启，观察电量数字与弧端是否分离。
2. 进入移动信号设置，将“双卡堆叠”放到中部。分别试上部、中部、下部，再调“信号图标大小”和“双卡排间距”。当前单卡只应显示一排四个点；预览里的第二排来自模拟双卡，不代表真机应有第二排。
3. 关闭“左右弧段联动”，分别调左右弧高、横向半轴、外移和上下开口；再打开联动应恢复对称。可切回“经典”比较。
4. 切换“胶囊”，左侧放时钟，中部放“双卡堆叠”，检查时钟与信号没有重叠；分别试短、默认、长胶囊。

## 其余验收

- 在亮色、暗色应用，以及锁屏、通知栏、控制面板中切换，检查尺寸、配色、原生图标和时间交接。
- Wi-Fi 连接/断开时检查中部 Wi-Fi 与网络类型候补；停用/启用 SIM 时注册阶段仍留空，没有“正在搜索”或短暂 SOS。
- 插电、满电和原生游戏助手旁路供电下检查颜色、灰度范围、功率和温度；闪电设为“不显示”时，模块与系统闪电都应隐藏。
- 关闭总开关应恢复原生显示，再开启恢复新布局；重启后所有设置应保留。

双卡物理顺序及切换数据卡需要两张实际 SIM 验收，目前单卡设备只能核对单卡显示。热重载初次覆盖 0.2.6 无法验证，需后续同签名更新或框架主动重载；被拒绝时旧布局应继续工作，重启 SystemUI 可应用新版。
