# ColorDuo 配置说明

本页适用于 ColorDuo 当前的 ColorOS 17 版本。安装和作用域设置见 [项目首页](../README.md)，固件与验证范围见 [适配记录](COLOROS17.md)。

## 初次设置

启用模块并重启 SystemUI 后，在绘图页选择样式、添加组件。圆环初始组件区为空，卡一和卡二的独立信号组件默认关闭；添加组件时会同时启用它需要的显示开关。

圆环的上、中、下每个区域各有一份有序列表。每帧显示列表中首个当前能够绘制的组件：闪电需要正在充电，Wi-Fi 弧需要有效信号，网络类型需要制式文字。后面的组件作为候补，同一区域每次显示一个组件。

新添加的组件会放到该区域列表的第一位，可以使用“上移”“下移”调整最终顺序。把组件移到另一区域，会从原区域移除它。

## 无 Wi-Fi 时显示网络类型

以下是一组可手动设置的圆环示例：

| 区域 | 从先到后的组件顺序 |
| --- | --- |
| 上部 | 电量数字 |
| 中部 | **Wi-Fi 弧 → 网络类型** |
| 下部 | 当前使用卡的信号点 |

把网络类型设为“环内”，确认中部列表中 Wi-Fi 在第一位、网络类型在第二位。连接 Wi-Fi 且有可绘制读数时显示弧形，断开后由网络类型接替。网络类型读取实际移动网络映射，如 5G、5GA 或 4G+。

电量数字只要有电量读数就能绘制；如果它排在网络类型前面，会优先占用该区域。可以将数字放到上部，或按需要调整候补顺序。

“预览状态 → 无 Wi-Fi”只改变模拟画面。要观察真机切换，可以断开手机的 Wi-Fi，同时保持移动网络可用。

仓库继承的 `docs/images/states.png` 来自 HyperDuo 旧版自动布局。当时断开 Wi-Fi 还会联动改变电量数字的位置。ColorDuo 当前采用区域优先列表，上表是当前配置方式；该旧图作为上游历史示意保留。

## 单卡与双卡

一组四个信号点表示一张卡的 0～4 级信号。卡一、卡二按真实卡槽分别取值，每组使用对应卡的读数。

双卡同时显示时，将“卡一信号点”和“卡二信号点”放在不同区域，例如上部与下部。把它们放入同一区域的优先列表，只会按列表选出一个组件。

环内信号点可放在上下缺口，中部用于读数。环外选择“堆叠信号”后，单卡用递增柱表示；两张卡都有读数时，另一张卡使用下方圆点。开启“仅显示上网卡”时，按实际数据卡选择读数。

## 环外组件

- 网络类型设为“环外”后，显示在电池旁。
- 信号设为“环外”且开启“堆叠信号”后，由模块绘制；关闭堆叠信号则交给系统原生图标。
- 充电功率与电池温度可分别开启；同时开启时共享位置，按两行显示。
- 环外组件的顺序、字号、字重和间距可分别调整，ColorOS 的原生布局为读数组预留空间。

功率按电池侧电流幅值乘以整包电压计算，会随实际充电状态和电量变化。`0.1.1` 起识别 Oplus 串联电芯数量；双串联只上报单节电压时折算为整包电压，已有整包电压时不重复翻倍。参考固件已校正电流单位；其他固件仍需核对。`0.2.0` 起仅在系统确认正在充电时显示功率，暂停、充满或拔电后隐藏；“温度仅充电时显示”遵循同一规则。它表示电池侧读数，充电器标称的最大功率属于不同测量位置。

## 充电闪电颜色

在“组件 → 充电闪电”中，普通充电、快充、闪充和超级闪充各有独立颜色，继续使用原有颜色选择器分别设置浅色模式和深色模式。

| 档位 | 协议 | 初始颜色 |
| --- | --- | --- |
| 充电 | 普通充电 | 保留原充电颜色；默认深色背景 `#34C759`、浅色背景 `#1F8F3D` |
| 快充 | PD / PPS / QC | 鲜绿色 `#00FF00` |
| 闪充 | UFCS / VOOC | 海军蓝 `#000080` |
| 超级闪充 | SVOOC | 高锰酸钾紫 `#800080` |

绘图页可分别选择这四种预览状态。电量环与充电闪电可分别设置各协议的浅深色：环内组件编辑电量环配色，充电闪电编辑自身配色；状态颜色为统一总开关。首次升级继承已有颜色，之后两组配色独立保存。恢复默认颜色会重置全部状态配色，包括电量环和闪电。

实际档位优先读取 Oplus 的 `/sys/class/oplus_chg/common/protocol_type`，（规范化协议枚举，避免将 fast_chg_type 的适配器 ID 当成协议）；不可读时使用系统充电模型中可用的协议标志；两者都无法识别时显示普通充电颜色。按协议判断，不按瞬时功率划档，拔线时清除之前的协议读数。

## Duo 状态规则

- 自动双卡读数按“数据卡、另一张卡”排列；独立的卡一、卡二组件保留物理卡槽对应关系。
- 模块接管信号时，无卡、无可用线路与持续仅紧急呼叫分别显示“无 SIM 卡”“无服务”和“SOS”。停用最后一张卡属于无可用线路。查询失败仍保留未知状态及原生提示。
- 注册过渡期间蜂窝信号和网络类型区域留空；系统仍在搜索网络时保持留空，注册成功立即恢复。注册结束后，无服务或仅紧急呼叫持续 3 秒再显示提示。明确停用全部线路或拔卡不等待注册计时。
- 系统明确上报充电暂停，或已确认开启原生旁路供电时使用灰色充电样式；零电流本身不代表暂停。旁路状态沿用暂停时的功率显示规则，退出旁路后恢复实际充电状态。绘图页可选择“充电暂停”预览。

依据 [Apple 状态图标说明](https://support.apple.com/zh-cn/guide/iphone/iphef7bb57dc/27/ios/27) 对齐状态语义；动画、像素比例与折叠屏场景仍需另行对照验证。

## 预览与实际读数

设置预览共用实际绘制规则，数据使用固定示例：卡一 2 级、卡二 4 级、网络类型 5GA。“充电”“快充”“闪充”“超级闪充”“无 Wi-Fi”等是模拟场景，不会改变手机的连接或充电状态。

真机按实际电量、卡槽、信号和网络类型更新。单卡手机也可能在预览中看到双卡示例；预览点亮两个点、真机点亮四个点，本身不代表读取错误。

## 升级与生效

同签名覆盖安装会保留 ColorDuo 配置，更新 APK 后需要重启 SystemUI。日常配置修改实时生效。

从 alpha6 更新至 `0.1.0` 正式版可直接覆盖安装，配置保留。

alpha6 起应用 ID 改为 `io.github.chorusfruit_233.colorduo` 并使用发布签名。旧 alpha 的 `io.github.chorusfruit233.colorduo` 是另一个应用，配置不会自动迁移。安装 alpha6 前，先在 LSPosed 停用旧包的 ColorDuo，再启用新包并勾选系统界面，避免两个模块同时接管。

alpha5 将同一组绘图配置应用到主状态栏、下拉通知栏、控制面板头部和锁屏的同类电池视图。alpha4 及以前只接管主状态栏，其他区域显示原生属于当时的移植缺口，与上游的跨页面处理尚未对齐。alpha5 的实际展开动画和跨页面配色仍需真机复测。

alpha1/alpha2 曾额外提供初始布局；alpha3 起恢复当前继承的共享默认值。已保存的旧布局会保留，可以在绘图页重新安排。模块关闭或组件交还系统后，对应原生显示应恢复。

异常反馈请提交到 [ColorDuo Issues](https://github.com/chorusfruit-233/ColorDuo/issues)，附上组件顺序、预览场景、真机连接状态及版本信息。
