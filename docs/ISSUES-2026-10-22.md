## 3. 本轮踩过的坑

这几条都是**操作失误**，不是设计问题，但代价很高：

| 坑 | 后果 | 教训 |
|---|---|---|
| 用「按行过滤」清理调试日志 | 把紧邻的 `this.settings = value` 一起删了，预览永远画默认值（#4） | 清理时只删**完整语句**，删完立即编译并确认逻辑 |
| 用正则做结构化替换 | 两次把方法签名/大段代码删掉，靠编译错误逐个修回 | 结构化改动**只做整行锚点替换**，每步编译 |
| 用 `cp` 整份覆盖设备 prefs | 缺键导致模块状态不一致，**手机锁屏卡住** | 改设备数据只用应用内 UI 或广播，永不覆盖 prefs 文件 |
| 用 `sed` 改 prefs | `ring_layout` 的 `\|` 被 shell 当管道，写坏两处数据 | 同上 |
| 用错的参照量算几何 | 高亮框用「直线段」宽而非「点行」宽，宽了一倍多 | 先量出实际墨迹范围，别从「看起来相关」的常量推导 |
