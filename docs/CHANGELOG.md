# ColorDuo 更新记录

本页记录 `chorusfruit-233/ColorDuo` 自身的版本，专注 ColorOS 17。HyperDuo 1.x 发布说明保留在 [release-notes/](release-notes/) 作为上游历史资料。

离线检查与构建结果、参考固件数据和真机反馈分别记录，具体边界见 [适配与验证记录](COLOROS17.md)。

## 0.3.12

- 修复圆环电量数字、充电闪电与环线间隔过大的问题，上下开口按实际内容尺寸调整。
- 开口联动数字字号、字重、字体和闪电大小，同时适配时间及网络类型文字。
- 同步预览点击范围与新环线位置，电量进度继续按实际可见弧长绘制。

关联 [#10](https://github.com/chorusfruit-233/ColorDuo/issues/10)。正式签名可覆盖升级，安装后重启 SystemUI 或手机。

已发布：[源码仓库](https://github.com/chorusfruit-233/ColorDuo/releases/tag/v0.3.12) · [Xposed 模块仓](https://github.com/Xposed-Modules-Repo/io.github.chorusfruit_233.colorduo/releases/tag/10032-0.3.12)。

## 0.3.11

- 整体尺寸调节范围扩展至 60%–300%，按实际绘制尺寸预留空间，并增加随当前 DPI 绘制的尺寸参考；升级保留原有布局和配置。
- 改进通知中心、控制中心头部和过渡镜像的占位；针对控制中心内部仍按原生行高测量的问题，同步约束布局自身的最小高度，缩小或停用后恢复系统尺寸。
- 新增独立“隐藏 HD 图标”开关：开启隐藏原生 HD，关闭交还系统，默认关闭；撤掉网络类型旁的 HD 标签。
- 调试日志增加绘制裁切、控件尺寸和父层级记录，便于正常下拉时定位显示问题。

正式签名，可覆盖安装并保留配置。升级后重启 SystemUI 或手机。控制中心过渡阶段的裁切修正仍待实机确认。

已发布：[源码仓库](https://github.com/chorusfruit-233/ColorDuo/releases/tag/v0.3.11) · [Xposed 模块仓](https://github.com/Xposed-Modules-Repo/io.github.chorusfruit_233.colorduo/releases/tag/10031-0.3.11)。

## 0.3.10

- 将真实 HD 状态并入网络类型，例如 `5G HD`；双卡区分 HD1、HD2 和 HD1+2，读取不完整时保留原生提示。
- 原生 HD 仅在模块网络类型接管且全部活动线路状态已知时隐藏，撤销上一版随信号直接隐藏的处理。
- 撤销未解决问题的硬件缓存绕过；调试日志新增实际绘制裁切、尺寸、变换及镜像层级采集。控制中心中途裁切尚未修复，本包用于实机定位。

## 0.3.9

- 避免 ColorOS 动画硬件缓存按原生控件边界截断放大图标，仅对模块接管并允许越界绘制的容器生效。
- 将独立 HD / VoLTE 图标纳入信号交接，提前登记隐藏规则，处理两个下拉面板重新出现 HD 的问题；归还信号后恢复系统规则。
- 保留 0.3.8 的通知中心高度修正，提供可覆盖安装的正式签名测试包。

## 0.3.8

- 通知中心同时增加外层独立头部和过渡容器的实际占位，修复放大后完全展开仍被遮挡。
- 为控制中心过渡动画的状态栏镜像预留绘制边界，修正首帧仍使用旧高度的问题；保留原生动画，关闭模块后恢复占位。
- 继续提供正式签名的实机测试包，可覆盖 0.3.7 并保留配置。

## 0.3.7

- 移除上一测试版的大字布局预设及撤销入口，只保留尺寸调节和尺寸参考；不再附带组件排序或字号修改。
- 修复通知栏和控制面板头部固定高度导致的遮挡：按图标、边距和内边距同步增高占位，保留 0dp 约束语义，退出接管时恢复原值。
- 原生重新写入头部高度或完整裁切范围时保持当前占位，移交系统时恢复最新原生设置；保留系统主动执行的局部动画裁切。
- 继续提供正式签名的实机测试草稿，不向模块仓发布。

## 0.3.6

- 整体尺寸扩展至 60%–300%，同时调整实际占位；保持电量主体的像素比例，信号或弧线变大时优先扩展边界。
- 按状态栏、锁屏和下拉面板各自的可用空间限制实际大小；共享容器的裁切状态在停止接管后恢复。
- 绘图页增加按当前 DPI 绘制的尺寸参考，以及可立即撤销的“大字电量”预设；升级保留原配置。
- 本版本先提供正式签名的实机测试草稿，不向模块仓发布。

## 0.3.5

合入 [jahn2007 的 PR #7](https://github.com/chorusfruit-233/ColorDuo/pull/7)，并整合审查与实机反馈修正。

- 新增双卡合并堆叠，支持上、中、下位置；单卡与双卡设置按所选布局显示。
- 新增分离双弧，可联动或独立调节；修正默认开口、电量数字和胶囊中部信号的排版。
- 信号图标大小与圆点粗细可分别调整；点阵垂直镜像同时作用于所有可见行，避免双排重合。
- 胶囊结构只显示可用参数，设置弹层支持滚动。
- 充电闪电统一为一个位置菜单：不显示、系统原生或指定位置；可选择暂停充电的灰度范围。
- 改进网络类型回退，修复 ColorOS 电量、颜色刷新时短暂露出原生图标的问题。
- 支持 API 102 热重载，并完善失败恢复；首次覆盖旧版仍需重启 SystemUI。

同签名可覆盖升级并保留配置。安装后重启 SystemUI 或手机。

## 0.3.4

- 点阵垂直镜像同时作用于所有可见行，单卡也生效；保留卡序、点距与独立排距，加粗时保证两排圆点不重叠。
- 增加直接执行设置列表的应用单元测试，以及单卡、双卡镜像绘制检查。

## 0.3.3

- 增强 Wi-Fi 断开与网络类型回退处理，电量和颜色更新时持续保留模块图标。

## 0.2.1

## 0.2.0

## 0.1.0-alpha5

- 撤回仅接管主状态栏的限制，扩展至锁屏和下拉通知栏/控制面板头部的同类电池实例，对齐上游按电池视图类接入的范围。
