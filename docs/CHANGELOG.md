# ColorDuo 更新记录

本页记录 `chorusfruit-233/ColorDuo` 自身的版本，专注 ColorOS 17。HyperDuo 1.x 发布说明保留在 [release-notes/](release-notes/) 作为上游历史资料。

离线检查与构建结果、参考固件数据和真机反馈分别记录，具体边界见 [适配与验证记录](COLOROS17.md)。

## 0.3.5

- 充电闪电统一为一个位置菜单：不显示、系统原生或指定布局位置，移除独立开关；隐藏时也隐藏系统闪电。
- 空胶囊不再绕过位置设置自动绘制闪电；保留已有可见性和组件布局，位置与显示状态一次同步。
- 合入 jahn2007 的 PR #7，包含双卡堆叠、分离双弧、网络类型回退与刷新修复，以及本项目审查和实机反馈修正。

## 0.3.4

- 胶囊结构只显示胶囊自己的五个参数，支持滚动；移除误混入且不可编辑的环形参数。
- 信号设置统一为“分别放置 / 合并堆叠”，按模式显示位置和单卡开关，避免重复选项；放置堆叠时同时移除旧聚合信号。
- 点阵垂直镜像同时作用于所有可见行，单卡也生效；保留卡序、点距与独立排距，加粗时保证两排圆点不重叠。
- 增加直接执行设置列表的应用单元测试，以及单卡、双卡镜像绘制检查。

## 0.3.3

- 引入 jahn2007 的 PR #7：双卡堆叠、分离椭圆、信号整体缩放、充电闪电开关及暂停充电灰度范围。
- 增强 Wi-Fi 断开与网络类型回退处理，电量和颜色更新时持续保留模块图标。
- 支持 API 102 热重载；后台忙碌时保留旧实例，失败时恢复回调和宿主。首次覆盖旧版仍需重启 SystemUI。
- 审查修正胶囊中部双卡与时钟重叠、分离弧默认开口挤压电量数字；保留实际默认电量字号和原有全部图标灰度默认值。
- 新增回归接入 CI。真机安装与布局验收见 [PR #7 审查与测试](PR7-REVIEW.md)。

## 0.2.6

- 优先通过 Oplus 充电服务读取成对的电流、电压；服务不可用、数据异常或过期时回退原有采样。
- 读取厂商串并联配置，串联电芯可使用两路实测电压求和；已有整包电压不再翻倍，并联电流口径未确认时保留平台回退。
- 采样移至后台，拔插电源清除旧样本；保留充满、暂停和原生旁路供电的显示规则。
- 可覆盖升级，安装后重启 SystemUI 或手机。

## 0.2.5

- 修复已验证 OPPO PMX110 固件充电功率持续显示 0W：校正电流单位，并在广播电压被截断时读取实际毫伏值。
- 异常电压无法读取时保持未知，不显示虚假的零功率；保留原有电芯识别和一加 13 的处理规则。
- 可覆盖升级，安装后重启 SystemUI 或手机。

## 0.2.4

- 接入 ColorOS 原生旁路供电的 PLC 状态，修复开启后仍按正常充电着色的问题；开启时使用灰色充电样式，关闭后恢复实际充电状态。
- 旁路状态沿用暂停时的功率显示规则；拔线、无线充电或状态读取失败时清除旁路判断并回退标准电池状态，不根据电流大小猜测。
- 可覆盖升级，安装后重启 SystemUI 或手机。

## 0.2.3

- 扩大圆环上下格的文字区域和开口，电量数字可以实际放大；默认字号 36 在一位、两位和三位电量下均可完整绘制。
- 中部文字按相邻格的占用情况分配空间，避免扩大字号后与上下组件重叠；信号点的位置保持原样。
- 中英文功能说明按当前默认值及调节范围显示，修正 Wi-Fi 弧线默认值、不同样式的字号范围和组件位置说明。
- 保留已保存的自定义字号，可覆盖升级；安装后重启 SystemUI 或手机。

## 0.2.2

- 修复缩短胶囊后电量 100% 仍留灰段，部分电量也按实际轮廓长度填充。
- 系统时间按当帧真正显示的组件交接，修复左格留空时丢失时间、Wi-Fi 等组件回退到时间时出现重复的问题；充电和注册状态切换遵循同一规则。
- 圆环上下格的电量字号滑杆按字体和可用空间给出上限，消除无效调节区间；已有配置保留。
- 可覆盖升级，安装后重启 SystemUI 或手机。

## 0.2.1

- 修复停用最后一张 SIM 卡后仍显示原生图标：无可用线路时显示“无服务”，接管 ColorOS 独立的无卡图标。
- 注册过渡期间蜂窝区域留空；系统仍在搜索网络时不显示临时文字或 SOS，注册成功立即恢复信号。注册结束后，同一线路的无服务或仅紧急呼叫状态持续 3 秒再显示对应提示。
- 保留未知读取和空间不足时的原生提示回退，可覆盖安装并保留配置；升级后重启 SystemUI 或手机。

## 0.2.0

- 对齐 iPhone Duo 的状态表达：接管信号时明确显示无 SIM 卡、无服务或 SOS；读取失败保留系统原生提示。
- 区分充电中、充电暂停和充满：暂停使用灰色充电样式，新增对应预览；暂停或充满后隐藏功率及仅充电时显示的温度。
- 自动双卡与环外信号优先显示数据卡，手动放置的卡一、卡二始终对应物理卡槽，切换数据卡不改变已保存布局。
- 修复环外组件退让后的空间计算；警告文字显示不下时保留原生信号提示。原生图标交接兼容列表和集合两种容器。
- 可同签名覆盖安装并保留配置；更新后重启 SystemUI 或手机。

## 0.1.1

- 修复参考一加 13 固件未识别双串联电芯、充电功率按单节电压少算的问题。
- 识别 Oplus 串联电芯数量，优先使用整包电压；仅有单节电压时折算，已有整包电压时不重复翻倍。功率公式、格式与配置保持上游规则。
- 可覆盖安装 `0.1.0` 并保留配置；升级后重启 SystemUI 或手机。

## 0.1.0

- 发布 `0.1.0` 正式版，versionCode 递增至 `10007`，源码仓库与模块仓库同步正式版标记。
- 沿用 alpha6 的应用 ID、发布签名及功能，可覆盖安装并保留配置；更新后重启 SystemUI 或手机。
- 发布流程显式同步正式版和 Latest 标记，重复执行时也会校正已有 Release 的状态。

## 0.1.0-alpha6

- 首个采用私有发布签名、准备提交模块仓的公开测试版，专注 ColorOS 17。
- 应用 ID 更正为 `io.github.chorusfruit_233.colorduo`，匹配 GitHub 账户的模块仓自动审核前缀，同步更新配置刷新广播。
- 拆分共用检查、测试包构建和手动发布准备，统一 Android 工具链、Gradle Wrapper 和缓存；文档修改跳过 APK 构建。
- 从实际 APK 生成产物名称、校验文件及构建信息，校验版本、签名和现代 Xposed 模块结构。
- release 改用外部私有签名，发布流程生成 Release 草稿及模块仓介绍素材，并强制检查包名前缀。

升级提示：新包名是独立应用，旧 alpha 配置不会自动迁移。请先在 LSPosed 停用旧包的 ColorDuo，再安装并启用新包，作用域选择系统界面后重启 SystemUI 或手机。

本版包含 alpha5 的锁屏及通知栏/控制面板接管改动，跨页面动画、配色及双卡仍需目标手机验证。

## 0.1.0-alpha5

- 撤回仅接管主状态栏的限制，扩展至锁屏和下拉通知栏/控制面板头部的同类电池实例，对齐上游按电池视图类接入的范围。
- 在各实例最近的图标行内查找原生图标，支持通知栏迁移状态栏行的场景，恢复旧行的所有权与类型可见性。
- 为 QS 的 ConstraintLayout 布局挂载环外读数；多个电池实例共用电话服务采样限频。
- 新增多页面接管、独立原生状态恢复、局部容器、视图迁移和头部读数挂载的离线检查；旧版代码会在新增接管断言中失败。实际过渡动画与配色待目标手机复测。

## 0.1.0-alpha4

- 修复网络类型采集：捕获实际 ViewModel、backing flow 和原生绑定模型，合并前后缀，支持 5GA、4G+ 等文字。
- 按参考固件的真实接口样本校正 mA → µA，解决功率被缩小 1000 倍并显示为 0.0W 的问题，保留共享功率公式和格式。
- 增加实际 Binder 电流样本、原生网络模型及空值的回归检查，继续执行共享源码一致性检查。
- [构建与检查通过](https://github.com/chorusfruit-233/ColorDuo/actions/runs/40080394596)，[下载测试包](https://github.com/chorusfruit-233/ColorDuo/actions/runs/40080394596/artifacts/12555017705)。两项修复待目标手机复测。

## 0.1.0-alpha3

- 恢复共享默认配置与迁移规则，撤回早期测试版本额外添加的初始布局和默认开启分卡。
- 环外信号、数据卡选择、功率温度格式、字体和排版复用共享函数；接入原生时钟与百分比交接条件。
- 增加 27 个共享源文件与固定上游基线的对比检查。
- 已通过构建和离线检查；用户随后反馈网络类型不显示、功率恒为零，由 alpha4 处理。

## 0.1.0-alpha2

- 修复缺少 InnerClass 元数据时无法识别已连接 Wi-Fi 模型的问题。
- 观察原生 Wi-Fi 图标转换路径，处理仓库初始值、断开与重连，分离 Wi-Fi 更新和电话服务采样限频。
- 补充 Wi-Fi 解析、连接恢复与图标所有权的回归检查，构建通过。

## 0.1.0-alpha1

- 引入 ColorOS 17 主状态栏适配器、独立应用 ID 和 ColorDuo 更新地址。
- 接入电池、颜色、VOOC、Wi-Fi 与分卡采样，保存并恢复原生视图和图标 slot。
- 提供 Gradle Wrapper、Android SDK 37 构建工作流与测试 APK。
- 目标设备日志确认适配器加载和主状态栏接管，Wi-Fi 问题在后续版本修复。
