# ColorDuo 更新记录

本页记录 `chorusfruit-233/ColorDuo` 自身的版本，面向 ColorOS 15–17。HyperDuo 1.x 发布说明保留在 [release-notes/](release-notes/) 作为上游历史资料。

离线检查与构建结果、参考固件数据和真机反馈分别记录，具体边界见 [适配与验证记录](COLOROS17.md)。

## 0.4.3-test1

- 针对 [#23](https://github.com/chorusfruit-233/ColorDuo/issues/23) 控制中心收起后图标再次上移的问题：保留过渡镜像的原生高度与居中位置，改为按绘制范围放宽裁剪；原生动画的局部裁剪仍保留。
- 覆盖日志中的 70/88 像素高度差、100%–300% 整体缩放、镜像缩放及布局变化、分离/重新绑定和关闭后的恢复。
- 包含已合入的 [#24](https://github.com/chorusfruit-233/ColorDuo/pull/24)：按需电池/内存采样、3/5/10 秒内存刷新间隔和重复重绘优化；接管信号或网络类型时保留 1 秒刷新兜底。

正式签名测试包，同时提供 modern / legacy，可覆盖本项目正式版并保留配置。安装后重启 SystemUI 或手机，保持原有布局验证控制中心收起是否仍有二次上移，并检查大尺寸图标有无裁剪。Find X10 Pro Max 的实机结果待反馈，本版不标记为 Latest。

## 0.4.2

- 增加 ColorOS 15/16 实验性适配：兼容旧版网络类型模型、制式/HD 图标和原生小时钟，按当前布局与活动 SIM 订阅网络状态。15/16 依据提供的 SystemUI APK 核对，仍待对应系统实机验证。
- 合入 [#21](https://github.com/chorusfruit-233/ColorDuo/pull/21)：新增内存占用百分比部件，修复胶囊填充角点；内存采样随组件、屏幕及息屏状态启停。
- 合入 [#22](https://github.com/chorusfruit-233/ColorDuo/pull/22)：补齐组件双轴位移并整理高级参数，保留 Wi-Fi 弧线定位；修正内存与信号设置项的归属和显示条件。
- 增加有容量上限的反射与几何缓存，修复实际尺寸预览的充电档位颜色。
- 同时提供同包名、同签名的 modern / legacy 正式包，可覆盖 `0.4.1` 和 `0.4.2-test1` 并保留配置。

20 组自动回归、modern / legacy 各 44 项单元测试及签名构建验证通过。安装后重启 SystemUI 或手机；系统与实机验证范围见 [兼容性说明](COLOROS-COMPATIBILITY.md)。

## 0.4.2-test1

- 增加 ColorOS 15/16 实验性适配：读取旧版网络类型模型，接管旧制式/HD 子视图，并兼容 ColorOS 15 的原生小时钟。依据 SystemUI 15.99.13、16.99.06 静态核对，尚待对应系统实机验证。
- 网络类型按当前布局和活动 SIM 订阅原生状态，关闭后释放；继续保留电话服务回退和 ColorOS 17 文字模型优先级。
- 包含 [#21](https://github.com/chorusfruit-233/ColorDuo/pull/21) 的内存占用部件和胶囊填充修复，以及 [#22](https://github.com/chorusfruit-233/ColorDuo/pull/22) 的组件双轴位移、缓存和充电预览修复；Wi-Fi 弧线保持原有定位。
- modern / legacy 共享上述功能与回归检查。正式签名测试包可覆盖旧版；安装后重启 SystemUI 或手机。

本轮先验证 ColorOS 17 无回退；15/16 的下拉动画、充电读数和各机型固件差异仍需实机反馈。详情见 [兼容性说明](COLOROS-COMPATIBILITY.md)。

- 全景息屏时停止充电流光及其逐帧重绘，保留静态电量轮廓和充电颜色；亮屏后恢复已开启的流光。此项修复已获实机确认。
- 同时提供正式签名的 modern / legacy 两版，可覆盖旧版及 `0.4.1-test1` 并保留配置。

安装后重启 SystemUI 或手机。

## 0.4.0

- 同一分支同时构建 **modern（libxposed API 102）** 与 **legacy（传统 Xposed API 82 起）**，共享 ColorOS 功能、布局和设置。
- 两版同包名、同签名，覆盖切换保留配置；legacy 使用持久化设置读取，支持重启后的配置恢复及实时修改。
- 应用内更新只下载当前 API 版本；Actions、源码 Release 和模块仓库同时提供两个 APK。
- modern 保留热重载；legacy 更新及两版互切后需要重启 SystemUI。

legacy 适配参考 [jahn2007 的分支](https://github.com/jahn2007/ColorDuo/tree/legacy)。两版构建和自动回归检查已覆盖，legacy 的设备兼容性仍需真机反馈。
